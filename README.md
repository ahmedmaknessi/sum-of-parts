# Sum of Parts

Animated explainers about money, business and the economy, made in code with [Remotion](https://www.remotion.dev).

See [CLAUDE.md](CLAUDE.md) for the channel, brand system, video format and project structure.

## Commands

**Start the Studio (preview)**

```console
npm run dev
```

**Render a video**

```console
npx remotion render BrandShowcase
```

**Lint and typecheck**

```console
npm run lint
```

Remotion is free for teams of up to 3. See the [Remotion license](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md).
